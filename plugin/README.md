## 📦 Installation

### Open WebUI Marketplace (Recommended)

1. Open Open WebUI
2. Go to Admin Settings → Community Plugins
3. Search "OpenDesigner"
4. Click Install
5. Restart Open WebUI

### Manual Installation

```bash
# Copy plugin functions
cp -r functions/* /path/to/openwebui/data/plugin-functions/

# Copy templates
cp -r templates /path/to/openwebui/data/templates/

# Restart Open WebUI
```
