## 📋 Deployment Options

### Option 1: Open WebUI Plugin (Recommended)
1. Clone repository
2. Copy functions to Open WebUI data directory
3. Restart Open WebUI
4. Done!

### Option 2: Docker Compose
1. Run `docker-compose up -d`
2. Access at http://localhost:3000
3. Functions auto-installed

### Option 3: Manual Install
1. Run `./install-opendesigner.sh`
2. Follow prompts
3. Restart Open WebUI
