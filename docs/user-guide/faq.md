# Frequently Asked Questions (FAQ)

Common questions about OpenDesigner answered.

---

## 🚀 Installation & Setup

### Q: What are the system requirements?
**A:** Open WebUI v0.10.0 or later. No additional dependencies required for basic usage.

### Q: How do I install OpenDesigner?
**A:** Three methods:
1. **Marketplace:** Search "OpenDesigner" in Community Plugins
2. **Manual:** Copy functions to Open WebUI data directory
3. **Docker:** Use docker-compose.yml

### Q: Can I install on an existing OpenWebUI instance?
**A:** Yes! Use `./install-for-dad.sh` for zero-friction installation.

### Q: Does it work with Ollama?
**A:** Yes! OpenDesigner works with any OpenWebUI-compatible model including Ollama, OpenAI, and more.

## 🎨 Features & Usage

### Q: How many features are included?
**A:** 15 comprehensive features across 4 phases:
- Phase 1: AI Design Iteration, Customization Panel, SEO
- Phase 2: Responsive Preview, Framework Export, Component States
- Phase 3: Multi-Page Generator, Design System, AI Images, A/B Testing
- Phase 4: Analytics, Figma Export, Performance Scoring, Design-to-Code, Collaboration

### Q: Can I export to React/Vue/Next.js?
**A:** Yes! Use the Framework Export feature to export to React, Vue, or Next.js with production-ready code.

### Q: How do I customize designs?
**A:** Use the Visual Customization Panel to adjust colors, fonts, spacing, and layout in real-time.

### Q: Can I generate images for my designs?
**A:** Yes! The AI Image Generation feature supports 6 styles: modern, colorful, minimal, artistic, photorealistic, and illustration.

### Q: Does it support responsive design?
**A:** Yes! The Responsive Preview Studio lets you preview on desktop, tablet, and mobile simultaneously.

## 🐛 Troubleshooting

### Q: Plugin not loading?
**A:** Check:
1. Open WebUI version (v0.10.0+)
2. Functions in correct directory
3. Restart Open WebUI
4. Check browser console

### Q: Preview not rendering?
**A:** Ensure:
1. Iframe sandbox enabled
2. No external URLs in HTML
3. No eval() in code

### Q: Export not working?
**A:** Verify:
1. Framework is supported
2. Browser compatibility
3. No security restrictions
