# Plugin Functions

## Pipe: Design Agent

The core function. Registers as "OpenDesign Design Agent" in the model dropdown.

### Request Flow

```
User message → Pipe.pipe(body)
  │
  ├─ 1. Detect intent (design vs. general chat)
  │     └─ If general: forward to configured LLM normally
  │
  ├─ 2. If design intent:
  │     ├─ Load user settings
  │     ├─ Load selected template
  │     ├─ Build enhanced prompt (system + template + design_system + user message)
  │     ├─ Call LLM (via Open WebUI's request context)
  │     ├─ Parse response (extract code blocks)
  │     ├─ Validate HTML (basic well-formedness check)
  │     ├─ Save version if new design
  │     └─ Return formatted response
  │
  └─ 3. Format response:
        ```html
        <!-- Generated by OpenDesign -->
        [HTML CODE]
        ```
        
        💡 *Click the "Generate Preview" button to see this in action*
```

### Key Methods

```python
class Pipe:
    async def pipe(self, body: dict, __user__=None, __event_emitter__=None, **kwargs):
        """Main entry point. Handles the full request/response cycle."""
    
    async def generate_html(self, user_message: str, context: dict) -> str:
        """Call LLM to generate HTML for the design request."""
    
    async def save_version(self, design: dict, html: str, prompt: str) -> str:
        """Save a new version to disk, return version ID."""
    
    async def parse_response(self, llm_response: str) -> dict:
        """Extract code blocks from LLM response, validate HTML."""
    
    def pipes(self) -> list[dict]:
        """Return list of models (manifold pattern):"""
        return [
            {"id": "opendesign-agent", "name": "OpenDesign Design Agent"},
            {"id": "opendesign-presentation", "name": "OpenDesign Presentations"},
            {"id": "opendesign-components", "name": "OpenDesign Components"},
        ]
```

### Manifold Pattern

The Pipe exposes **three models** from one function:

| Model ID | Purpose |
|----------|---------|
| `opendesign-agent` | General design generation (landing pages, dashboards, etc.) |
| `opendesign-presentation` | Slide deck generation with presenter notes |
| `opendesign-components` | UI component generation (buttons, cards, forms, navbars) |

Users select the model they need from the dropdown. The Pipe routes to the appropriate prompt template.

### Filter Injection Examples

When a design prompt is detected:

1. **Design system tokens** are injected:
   ```
   Use these CSS custom properties for consistent styling:
   --color-bg: #FFFFFF, --color-text: #1A1A1A, --color-accent: #737373
   ```

2. **Accessibility requirements** are appended:
   ```
   All elements must be keyboard navigable. Use semantic HTML5.
   Include ARIA labels on interactive elements. Ensure 4.5:1 contrast ratio.
   ```

3. **Template suggestions** from user history:
   ```
   User previously used "landing/hero" template successfully.
   Consider suggesting similar layouts.
   ```
